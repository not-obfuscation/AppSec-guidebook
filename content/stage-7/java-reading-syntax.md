# Синтаксис Java на уровне чтения

Уровень **L3** · время 20 мин

Минимальная программа на Java целиком — и прогон её компиляции и запуска
(OpenJDK 17):

```java
public class Hello {
    private static int count = 0;

    public static void main(String[] args) {
        count++;
        System.out.println("привет из Java, вызов " + count);
    }
}
```

```text
$ javac Hello.java && java Hello
привет из Java, вызов 1
```

Восемь строк, а в них уже весь словарь ревьюера: класс, поле, метод,
модификаторы, точка входа. Не заглядывая в разбор: какая строка этих
восьми в многопоточном сервере потребует второго взгляда? Эта тема —
справка для чтения чужого
Java-кода на ревью: писать на языке не потребуется, но читать
придётся много. Ниже — как устроено объявление и на что смотреть
в первую очередь.

## 0. Коротко

Java-код читается по структуре: класс с модификаторами, внутри — поля
(состояние) и методы (поведение) с типами на виду. Управление потоком
знакомо по C-подобным языкам: if, for, while, return. Ошибки идут
исключениями, и сигнатура метода с `throws` объявляет их заранее.
Аннотации сами по себе — метаданные, но фреймворк может читать их как
конфигурацию: `@Override` не меняет семантику — это маркер для
компилятора, а `@RequestMapping` регистрирует обработчик. `static`
означает общее для всех экземпляров состояние — первое место, где в
ревью ищут общие изменяемые данные. То же в терминах, которыми это
обсуждают.

**Зачем это в работе AppSec-инженера.** Код на Java встречается в ревью
без среды разработки: diff в системе ревью, фрагмент в отчёте сканера.
Чтение «по структуре» покрывает большую часть находок: публичное поле,
статический изменяемый список, исключение, проглоченное пустым catch.

## 3. Механика

**Откуда это взялось.** Java проектировалась для больших команд: читаемость
чужого кода ценой многословия. Отсюда явные типы и модификаторы доступа в
каждом объявлении — то, что в других языках уговор, здесь часть синтаксиса.

Объявление класса идёт в фиксированном порядке (dev.java): модификаторы,
имя, `extends` с единственным родителем, `implements` со списком
интерфейсов, тело в фигурных скобках. Внутри три вида переменных, и их
различие — вопрос ревью: поля живут в объекте, локальные переменные — в
методе, параметры — во входе метода. Модификаторы доступа читаются прямо:
public доступен всем, private — только своему классу. Приём «поле
private, доступ через метод» — это инкапсуляция, а не украшение.

Управление потоком перечисляется за минуту. Ветвление — if-then-else,
циклы — while и for, включая форму «for по коллекции». Выход из метода —
return, в циклах работают break и continue, разбор вариантов — switch.
Из сводки операторов для ревью важны два места. Оператор `==` у объектов
сравнивает ссылки, а не содержимое: строки сравнивают через equals. И
операторы `&&` с `||` ленивы: правая часть не вычисляется без нужды.

Ошибки — исключения. Метод объявляет проверяемые исключения словом
`throws` в сигнатуре, а читатель обработки ищет try-catch: пустой блок
catch — это проглоченный сбой, находка по форме. Исключение, вылетевшее
выше всех catch, уходит вызывающему — и в веб-приложении обычно в общий
обработчик фреймворка.

Два чтения не по словарю, а по смыслу. Аннотация — запись вида `@Имя`
перед объявлением: языком это метаданные без эффекта, а фреймворками
(Spring, Jakarta) читаются как конфигурация. При ревизии вопрос один:
кто читает эту аннотацию. И `static`: поле или метод принадлежит классу,
а не экземпляру. Изменяемое static-поле — общее состояние всех запросов
сразу, и в многопоточном сервере это место для гонок.

## 13. Источники

1. Learn Java, dev.java; реестр `java-tutorial-language`. Разделы:
   карта учебника (Language Basics, Classes and Objects, Exceptions).
   <https://dev.java/learn/>
2. Control Flow Statements, dev.java; реестр `devjava-controlling-flow`.
   Разделы: if-then-else, while и do-while, обе формы for, break,
   continue, return, yield.
   <https://dev.java/learn/language-basics/controlling-flow/>
3. Summary of Operators, dev.java; реестр `devjava-summary-of-operators`.
   Разделы: таблицы операторов — присваивание, арифметика, сравнение,
   условные и побитовые, `instanceof`.
   <https://dev.java/learn/language-basics/all-operators/>
4. Creating Classes, dev.java; реестр `devjava-creating-classes`.
   Разделы: состав объявления класса, виды переменных, модификаторы
   доступа, соглашения об именах.
   <https://dev.java/learn/classes-objects/creating-classes/>
