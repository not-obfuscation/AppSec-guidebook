# Лаба: контексты вставки

Формат Secure Code Game: чините `code.mjs`, пока `hack.mjs` и `tests.mjs`
не станут зелёными одновременно.

**Цель одной фразой:** добиться, чтобы `hack.mjs` вышел с кодом 0, а
`tests.mjs` продолжил выходить с кодом 0.

Карточка товара на `127.0.0.1:8124`. Одно присланное значение выводится в
пяти местах разметки: в теле документа, в значении атрибута в кавычках, в
значении атрибута без кавычек, в адресе ссылки и в строковом литерале
внутри элемента `script`. Автор карточки про экранирование знал и
применил его везде — сущностями HTML в четырёх местах и обратным слэшем
перед кавычкой в скрипте. Три места из пяти это не закрывает.

Всё исполняется локально: сеть браузеру перекрыта флагом
`--host-resolver-rules=MAP * ~NOTFOUND, EXCLUDE 127.0.0.1`.

## Запуск

Нужен Node.js 20 или новее (проверено на v26.7.0) и headless-браузер из
кеша puppeteer, который уже стоит в `tools/node`.

```bash
cd pilot/lab/xss-contexts
node tests.mjs   # ожидается: Упало проверок: 0, код возврата 0
node hack.mjs    # ожидается: ЭКСПЛОЙТ СРАБОТАЛ, код возврата 1
```

Прогнать то же против образцового решения:

```bash
LAB_TARGET=solution.mjs node hack.mjs    # ЭКСПЛОЙТ НЕ СРАБОТАЛ, код 0
LAB_TARGET=solution.mjs node tests.mjs   # Упало проверок: 0, код 0
```

Посмотреть глазами в своём браузере:

```bash
node serve.mjs   # печатает адрес и не завершается; Ctrl+C — стоп
```

## Отдельная задача «почини»

Пять мест — четыре разных правила, и одной функцией их не закрыть.

Атрибут без кавычек чинится не экранированием, а кавычками: пока их нет,
пробел в значении заканчивает атрибут и всё, что дальше, браузер читает
как новые атрибуты. Опыт 4 показывает вторую сторону того же: исходная
карточка теряет хвост законного значения `скидка 20 %` — то есть
неправильна не только по безопасности.

Адрес ссылки чинится проверкой схемы. Экранирование сущностями его не
трогает вовсе: в строке `javascript:window.__ran=2` нет ни одного знака,
который сущности заменяют.

Значение в скрипте чинится не экранированием кавычки. Разбор разметки
идёт раньше разбора кода, и закрывающая последовательность элемента
`script` выходит из него независимо от кавычек.

Наблюдаемый критерий: `node tests.mjs` печатает `Упало проверок: 0` и
выходит с кодом 0 после того, как `node hack.mjs` вышел с кодом 0.

Замер на этой лабе — четыре варианта `code.mjs`:

| Что делает `code.mjs` | провалено в `hack.mjs` | в `tests.mjs` |
|---|---|---|
| сущности везде, слэш в скрипте (исходный) | 4 | 0 |
| плюс кавычки вокруг атрибута | 2 | 0 |
| плюс проверка схемы адреса | 1 | 0 |
| плюс значение скрипта литералом JSON (`solution.mjs`) | 0 | 0 |

Четыре провала в первой строке — это три эксплойта и один контроль: та
самая потеря хвоста в атрибуте без кавычек.

```bash

```

## Сброс

Состояние держится в памяти процесса, между запусками ничего не
остаётся. Чтобы вернуть исходный `code.mjs`, восстановите его из
репозитория гайдбука.

## Удаление

```bash
rm -rf pilot/lab/xss-contexts
```

Ничего вне этого каталога лаба не создаёт и не меняет.
