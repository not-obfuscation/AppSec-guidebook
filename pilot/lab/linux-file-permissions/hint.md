# Подсказка

Подсказка одна.

Права новому файлу назначает не только режим из вызова `os.open`, но и
маска процесса: ядро срезает из запрошенного режима биты, которые стоят
в umask. Маска может только убирать биты и никогда не добавляет. Значит,
вызов, который просит режим шире нужного, отдаёт итог на откуп
окружению. Попросите у ядра режим, при котором читать и писать может
только владелец, — тогда любая маска оставит файл закрытым.
