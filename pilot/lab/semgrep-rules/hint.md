# Подсказка

Начните с образца по вызову и посмотрите, какой из подставленных дефектов он
не найдёт.

В стенде на Go текст запроса в одном месте собирается `fmt.Sprintf` и
присваивается переменной, а в вызов уходит уже готовая строка. Образец,
описывающий только вызов, туда не дотянется. В языке правил есть способ
описать два оператора подряд с любым числом операторов между ними.

В стенде на Python обратная беда: заготовка уже находит оба дефекта, но
срабатывает и там, где запрос вообще не собирается из частей. Посмотрите на
последний образец в списке стоков и спросите себя, что он совпадает.
