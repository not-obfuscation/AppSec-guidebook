# Лаба: инъекция команд ОС

Формат Secure Code Game: чините `code.py`, пока `hack.py` и `tests.py`
не станут зелёными одновременно.

**Цель одной фразой:** добиться, чтобы `hack.py` вышел с кодом 0, а
`tests.py` продолжил выходить с кодом 0.

Всё исполняется локально, без сети и без Docker. Внешний инструмент здесь
изображает `echo` — команда безопасная и есть везде, а механизм инъекции
от выбора инструмента не зависит. Ничего вне каталога лабы команда не
трогает. Приёмы из `hack.py` привязаны к этой лабе.

## Запуск

Нужен Python 3.9 или новее. Проверено на 3.14.7.

```bash
cd pilot/lab/os-command-injection
python3 tests.py   # ожидается: упало 0, код возврата 0
python3 hack.py    # ожидается: ЭКСПЛОЙТ СРАБОТАЛ, код возврата 1
```

Против образцового решения:

```bash
LAB_TARGET=solution.py python3 hack.py
LAB_TARGET=solution.py python3 tests.py
```

## Что проверяет эксплойт

| Опыт | Приём | Что получает атакующий |
|---|---|---|
| 1 | `; echo RESULT=$((7*11))` в подписи | исполнение второй команды (в выводе `RESULT=77`) |
| 2 | контроль: обычная подпись | подпись должна строиться |
| 3 | контроль: `;` в подписи как текст | после починки символ печатается, не исполняется |

Признак исполнения выбран так, чтобы его нельзя было спутать с текстом:
`RESULT=77` появляется в выводе, только если оболочка посчитала арифметику.
При запуске без оболочки эти символы попадают в подпись буквально.

## Файлы

| Файл | Что это |
|---|---|
| `code.py` | То, что чините |
| `hack.py` | Эксплойт; зелёный, когда метасимволы стали текстом |
| `tests.py` | Функциональность; должна остаться зелёной |
| `hint.md` | Одна подсказка |
| `solution.py` | Образцовое решение |
| `labtarget.py` | Загрузчик проверяемого модуля |

## Сброс

Состояния лаба не держит: команда чистая, файлов не создаёт. Чтобы вернуть
исходный `code.py`, восстановите его из репозитория гайдбука.

## Удаление

```bash
rm -rf pilot/lab/os-command-injection
```

Ничего вне этого каталога лаба не создаёт и не меняет.
