# Лаба path-traversal: проверка пути до канонизации

Служба отдаёт клиенту счета из базового каталога, имя файла приходит от
клиента. О выходе за каталог разработчик подумал: перед открытием стоит
проверка, что собранный путь начинается с базового каталога. Проверка стоит
раньше, чем нужно, — переходы вверх из пути ещё не убраны, и разбирает их уже
операционная система при открытии файла.

## Файлы

| файл | что это |
|---|---|
| `code.py` | уязвимый модуль: сверка с базовым каталогом до канонизации |
| `solution.py` | образец починки: `realpath`, затем `commonpath` |
| `hack.py` | эксплойт: выход за базовый каталог; возврат 0 — почат, 1 — уязвимо |
| `tests.py` | функциональность выдачи: должна остаться зелёной |
| `sandbox.py` | дерево каталогов лабы во временном каталоге |
| `labtarget.py` | загрузка проверяемого модуля (`LAB_TARGET=solution.py`) |
| `hint.md` | одна подсказка |

## Как запускать

```text
cd pilot/lab/path-traversal
../../../.venv-tools/bin/python hack.py      # против code.py: 3 из 3 опытов
../../../.venv-tools/bin/python tests.py     # функциональность: 0 упало
LAB_TARGET=solution.py ../../../.venv-tools/bin/python hack.py    # 0 опытов
LAB_TARGET=solution.py ../../../.venv-tools/bin/python tests.py   # 0 упало
```

## Цель одной фразой

Добиться, чтобы `hack.py` вышел с кодом 0 (за базовый каталог выйти нельзя), а
`tests.py` продолжил выходить с кодом 0 (подкаталоги и точки внутри базового
каталога работают).

## Задача «почини»

Закройте выход за базовый каталог в `read_document`. Три опыта эксплойта —
переход вверх из корня выдачи, переход вверх из законного подкаталога и
символическая ссылка изнутри наружу — должны получить отказ. Пять проверок
функциональности должны остаться зелёными: путь `archive/../invoice-2026-02.txt`
законен, потому что не выходит за базовый каталог.

## Правило SAST

`pilot/semgrep/path-join-user-input.yaml` ловит открытие файла по пути,
собранному `os.path.join` из значения запроса без канонизации: на `code.py`
одна находка, на `solution.py` — ноль.
Сверка: `.venv-tools/bin/python pilot/semgrep/check.py path-join`.

Всё исполняется локально, к сети не обращается и применимо только к этой лабе.

## Сброс

Дерево каталогов ставится во временный каталог системы при каждом
запуске, между запусками ничего не остаётся. Чтобы вернуть исходный
`code.py`, восстановите его из репозитория гайдбука.

## Удаление

```bash
rm -rf pilot/lab/path-traversal
```

Вне этого каталога лаба создаёт только дерево во временном каталоге
системы (префикс `lab-path-traversal-`); оно остаётся там до очистки
системой.
