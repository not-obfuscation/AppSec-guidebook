# Лаба: SQL-инъекции, классические и UNION

Формат Secure Code Game: чините `code.py`, пока `hack.py` и `tests.py`
не станут зелёными одновременно.

**Цель одной фразой:** добиться, чтобы `hack.py` вышел с кодом 0, а
`tests.py` продолжил выходить с кодом 0.

Всё исполняется локально, только стандартной библиотекой Python
(модуль `sqlite3`), без сети и без Docker. HTTP не поднимается: функции
витрины вызываются напрямую, база живёт в памяти процесса. Приёмы из
`hack.py` привязаны к этой лабе и применимы только к ней.

## Запуск

Нужен Python 3.9 или новее. Проверено на 3.14.7.

```bash
cd pilot/lab/sqli-basics
python3 tests.py   # ожидается: упало 0, код возврата 0
python3 hack.py    # ожидается: ЭКСПЛОЙТ СРАБОТАЛ, код возврата 1
```

Прогнать те же проверки против образцового решения:

```bash
LAB_TARGET=solution.py python3 hack.py
LAB_TARGET=solution.py python3 tests.py
```

## Что проверяет эксплойт

| Опыт | Приём | Что получает атакующий |
|---|---|---|
| 1 | `administrator'--` в имени | вход администратором без пароля |
| 2 | `Gifts'--` в категории | товары, снятые с витрины |
| 3 | `' OR '1'='1` в категории | весь каталог мимо фильтра |
| 4 | `' UNION SELECT ...` в категории | имя и пароль из чужой таблицы |
| 5 | контроль: обычный поиск | выдача должна остаться |
| 6 | контроль: честный вход | вход по паролю должен остаться |

Опыты 1–4 — четыре классических приёма из одной причины: текст запроса
и данные склеены в одну строку. Опыты 5 и 6 следят, чтобы починка не
свелась к запрету всего подряд.

## Сброс

Состояние держится в памяти процесса, между запусками ничего не
остаётся. Чтобы вернуть исходный `code.py`, восстановите его из
репозитория гайдбука.

## Удаление

```bash
rm -rf pilot/lab/sqli-basics
```

Ничего вне этого каталога лаба не создаёт и не меняет.
