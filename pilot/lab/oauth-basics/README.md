# Лаба oauth-basics: неявный поток отдаёт токен через браузер

Приложение (client) входит через внешний сервер авторизации. Сеть не
поднимается: сервер авторизации — функция `authorize()`, возвращающая
переадресацию обратно на client. Дефект в типе потока: `response_type=token`
(неявный поток) кладёт токен доступа во фрагмент адреса переадресации. Фрагмент
идёт через браузер и оседает в истории, журналах и заголовке Referer.

## Файлы

| файл | что это |
|---|---|
| `code.py` | уязвимый модуль: неявный поток (`response_type=token`) |
| `solution.py` | образец починки: поток кода (`response_type=code`) |
| `hack.py` | эксплойт: токен в адресе; 0 — почат, 1 — уязвимо |
| `tests.py` | функциональность входа: должна остаться зелёной |
| `labtarget.py` | загрузка проверяемого модуля (`LAB_TARGET=solution.py`) |
| `hint.md` | одна подсказка |

## Как запускать

```text
cd pilot/lab/oauth-basics
../../../.venv-tools/bin/python hack.py       # против code.py: 2 из 2 признаков
../../../.venv-tools/bin/python tests.py      # функциональность: 0 упало
LAB_TARGET=solution.py ../../../.venv-tools/bin/python hack.py    # 0 признаков
LAB_TARGET=solution.py ../../../.venv-tools/bin/python tests.py   # 0 упало
```

## Цель одной фразой

Добиться, чтобы `hack.py` вышел с кодом 0 (токен не появляется в адресе), а
`tests.py` продолжил выходить с кодом 0 (вход выдаёт токен клиенту).

## Задача «почини»

Переведите запрос авторизации на `response_type=code`. Токен доступа клиент
получает обменом кода по обратному каналу, а не из фрагмента адреса.

## Правило SAST

`pilot/semgrep/oauth-implicit-grant.yaml` ловит `response_type=token` и
`grant_type=password`: на `code.py` одна находка, на `solution.py` — ноль.
Сверка: `.venv-tools/bin/python pilot/semgrep/check.py oauth-grant`.

Всё локально, к сети не обращается, применимо только к этой лабе.

## Сброс

Состояние держится в памяти процесса, между запусками ничего не
остаётся. Чтобы вернуть исходный `code.py`, восстановите его из
репозитория гайдбука.

## Удаление

```bash
rm -rf pilot/lab/oauth-basics
```

Ничего вне этого каталога лаба не создаёт и не меняет.
