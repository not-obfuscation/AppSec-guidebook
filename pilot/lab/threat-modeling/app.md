# Учебная витрина: описание для сессии моделирования

Витрина каталога — то же учебное приложение, что в лабе sqli-basics
этапа 1. Устройство:

- Поиск товаров по категории: ввод пользователя подставляется в запрос
  к базе SQLite (в лабе этапа 1 — склейкой, здесь это просто факт
  устройства).
- Вход в кабинет: логин и пароль против таблицы пользователей; после
  входа выдаётся cookie с идентификатором сессии.
- Административный раздел: список товаров, включая невыпущенные
  (released=0). Доступен по адресу /admin пользователям с ролью admin.
- База SQLite лежит файлом рядом с приложением. Резервных копий нет.
- Всё ходит по HTTP через обратный прокси, который завершает TLS.

Диаграмму рисуйте сами: внешний пользователь, прокси, приложение, база,
администратор. Границы доверия — там, где данные переходят между
узлами с разным уровнем доверия.
