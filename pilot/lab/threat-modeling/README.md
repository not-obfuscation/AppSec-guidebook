# Лаба: сессия моделирования угроз

Формат — задача чтения: по описанию учебной витрины (`app.md`)
заполните бланк `answers.csv`, пока `check.py` не ответит «зачтено».

**Цель одной фразой:** добиться, чтобы `check.py` вышел с кодом 0.

Всё офлайн, из зависимостей — Python и PyYAML (стоит в окружении
проверок проекта). Диаграмму рисуйте на бумаге или в любом редакторе;
проверялке нужен только бланк.

## Запуск

```bash
cd pilot/lab/threat-modeling
python3 check.py   # на пустом бланке — расхождения по всем шести строкам
```

## Файлы

| Файл | Что это |
|---|---|
| `app.md` | Описание учебной витрины |
| `answers.csv` | Бланк реестра угроз — заполняется |
| `key.yaml` | Эталон разметки (тип, граница, STRIDE) |
| `check.py` | Проверялка |
| `hint.md` | Одна подсказка |
| `solution.csv` | Эталон заполнения, открыт без условий |

## Сброс

Верните `answers.csv` в исходное состояние из репозитория гайдбука.

## Удаление

```bash
rm -rf pilot/lab/threat-modeling
```

Ничего вне этого каталога лаба не создаёт и не меняет.
