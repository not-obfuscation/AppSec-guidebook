# Лаба: XSS в DOM

Формат Secure Code Game: чините `code.js`, пока `hack.mjs` и `tests.mjs`
не станут зелёными одновременно.

**Цель одной фразой:** добиться, чтобы `hack.mjs` вышел с кодом 0, а
`tests.mjs` продолжил выходить с кодом 0.

Кабинет на `127.0.0.1:8122` и чужая площадка на `127.0.0.1:8123`. Сервер
кабинета отдаёт постоянную разметку и ничего не подставляет: весь дефект
живёт в браузере. Три значения приезжают мимо сервера — имя раздела из
фрагмента адреса, черновик из имени окна, адрес возврата из параметра, —
и все три попадают в стоки, которые разбирают их как разметку или как
адрес.

Опыт 1 печатает заодно, что сервер увидел за этот запрос: нагрузки в
списке нет. Фрагмент адреса браузер серверу не отправляет, поэтому
серверное экранирование этот дефект не закрывает и журнал сервера его не
покажет.

Всё исполняется локально: сеть браузеру перекрыта флагом
`--host-resolver-rules=MAP * ~NOTFOUND, EXCLUDE 127.0.0.1`.

## Запуск

Нужен Node.js 20 или новее (проверено на v26.7.0) и headless-браузер из
кеша puppeteer, который уже стоит в `tools/node`.

```bash
cd pilot/lab/xss-dom
node tests.mjs   # ожидается: Упало проверок: 0, код возврата 0
node hack.mjs    # ожидается: ЭКСПЛОЙТ СРАБОТАЛ, код возврата 1
```

Прогнать то же против образцового решения:

```bash
LAB_TARGET=solution.js node hack.mjs    # ЭКСПЛОЙТ НЕ СРАБОТАЛ, код 0
LAB_TARGET=solution.js node tests.mjs   # Упало проверок: 0, код 0
```

Посмотреть глазами в своём браузере:

```bash
node serve.mjs   # печатает два адреса и не завершается; Ctrl+C — стоп
```

## Отдельная задача «почини»

Стока три, а починки две, и это главное в лабе. Имя раздела и черновик —
текст, и для них меняется сток. Адрес возврата — адрес, и для него сток
менять некуда: `href` обязан остаться `href`. Там проверяется само
значение — схема и форма пути, — потому что `javascript:` не
экранируется сущностями и никаким экранированием не закрывается.

Наблюдаемый критерий: `node tests.mjs` печатает `Упало проверок: 0` и
выходит с кодом 0 после того, как `node hack.mjs` вышел с кодом 0.

Замер на этой лабе — четыре варианта `code.js`:

| Что делает `code.js` | провалено в `hack.mjs` | в `tests.mjs` |
|---|---|---|
| три стока без проверок (исходный) | 3 | 0 |
| `textContent` только у раздела | 2 | 0 |
| `textContent` у раздела и черновика | 1 | 0 |
| плюс проверка адреса возврата (`solution.js`) | 0 | 0 |

## Сброс

Состояние держится в памяти процессов, между запусками ничего не
остаётся. Чтобы вернуть исходный `code.js`, восстановите его из
репозитория гайдбука.

## Удаление

```bash
rm -rf pilot/lab/xss-dom
```

Ничего вне этого каталога лаба не создаёт и не меняет.
