# Подсказка

Одна на всю лабу.

«Список переменной длины параметром не передать» — полуправда. Передать
нельзя один параметр-список, но можно сгенерировать по заполнителю `?` на
каждый элемент и связать значения. Число заполнителей равно длине списка,
сами значения едут отдельным аргументом `execute`. Текст запроса при этом
остаётся постоянным: в нём только запятые и вопросительные знаки, ни одного
присланного символа.
