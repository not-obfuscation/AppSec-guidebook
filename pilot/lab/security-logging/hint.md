# Подсказка

Подсказка одна.

Посмотрите на `dump_log()` глазами того, кто получил файл журнала и
ничего больше. Ему не должно доставаться ничего, с чем можно прийти
обратно: ни пароля из записи о входе, ни токена из записи о выдаче.
Токену нужен заменитель, по которому запись находят, а открыть им
нельзя, — односторонняя функция из `hashlib` это даёт.

Отдельно проверьте, что в записи печатается данными, а что разметкой:
имя пользователя приходит из запроса, и перевод строки в нём рождает
вторую запись, которой не было.
