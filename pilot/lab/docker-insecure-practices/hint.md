# Подсказка

Подсказка одна.

Функция мониторинга читает список контейнеров — это один вызов одной
точки API. Контейнеру для этого не нужен сокет целиком: дайте ему
канал, который умеет ровно этот вызов и отвечает отказом на всё
остальное. Демон при этом остаётся общим: администратор хоста ходит в
него напрямую, мониторинг — через узкий канал.
