# Лаба: прогон ASVS уровня L1 по учебному приложению

Формат — задача чтения: по снимку витрины (`app.md`) проставьте вердикт
и признак каждому требованию в `answers.csv`, пока `check.py` не ответит
«зачтено».

**Цель одной фразой:** добиться, чтобы `check.py` вышел с кодом 0.

Всё офлайн, из зависимостей — Python и PyYAML (стоит в окружении
проверок проекта). Тексты требований берутся из документа ASVS v5.0.0 —
адрес в теме.

## Запуск

```bash
cd pilot/lab/owasp-asvs
python3 check.py   # на пустом бланке — расхождения по всем шести строкам
```

## Файлы

| Файл | Что это |
|---|---|
| `app.md` | Снимок учебной витрины |
| `answers.csv` | Бланк вердиктов — заполняется |
| `key.yaml` | Эталон вердиктов |
| `check.py` | Проверялка |
| `hint.md` | Одна подсказка |
| `solution.csv` | Эталон заполнения, открыт без условий |

## Сброс

Верните `answers.csv` в исходное состояние из репозитория гайдбука.

## Удаление

```bash
rm -rf pilot/lab/owasp-asvs
```

Ничего вне этого каталога лаба не создаёт и не меняет.
