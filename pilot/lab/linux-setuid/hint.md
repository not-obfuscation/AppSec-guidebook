# Подсказка

Подсказка одна.

Обёртка с битом setuid root исполняется с правами владельца файла, но
наследует окружение того, кто её вызвал. Всё, что она берёт из
переменных окружения — пути поиска программ, каталоги библиотек,
локаль, — выбирает вызывающий. Безопасная обёртка заменяет окружение
своим: фиксированный список системных каталогов для поиска программы и
белый список из тех переменных, которые действительно нужны. Так
поступает sudo с его env_reset.
