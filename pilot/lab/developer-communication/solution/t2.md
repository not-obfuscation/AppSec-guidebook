# Т-2: комментарий FIXME на главной

Отчёт, из которого взята находка: `reports/zap-10027.txt`.

## Вердикт

не дефект

## Шаги

```text
GET /
```

## Ожидалось

Главная страница без служебных комментариев в разметке.

## Получено

Комментарий на месте, ровно тот, что нашло правило:

```text
<!-- FIXME: убрать тестовый вход перед релизом -->
```

## Влияние

Никакого. Комментарий не раскрывает ни адреса, ни имени, ни признака —
только намерение автора. Правило 10027 ищет слово `FIXME` выражением
`\bFIXME\b` и сообщает о находке уровня «информационно»; дефекта за ней нет.

Влияние есть у самой заявки, и оно отрицательное: разработчик тратит время на
разбор, а следующую заявку читает уже с меньшим доверием.

## Предложение

Не заводить задачу. Строку отчёта закрыть как не дефект, указав признак:
комментарий не содержит данных. Если такие строки приходят каждый прогон —
подавить правило адресно и записать причину рядом с подавлением.

## Срок

Не назначается: срок бывает у дефекта.
