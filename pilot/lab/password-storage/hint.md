# Подсказка

Подсказка одна.

Посмотрите на `export_dump()` глазами того, у кого на руках только этот
дамп. Ему нужно, чтобы работа над одной записью не помогала со всеми
остальными и чтобы каждая догадка стоила заметного времени. Первое даёт
уникальное случайное значение, которое хранится рядом с хешем и не
является секретом. Второе — функция, у которой есть настраиваемая цена;
в стандартной библиотеке Python такая одна, и она названа в
`hashlib`, раздел «Key derivation».

Отдельно подумайте, что делать с записями, которые уже лежат в базе:
исходных паролей для них нет ни у кого. Тест «пользователь из старой
базы входит» упадёт, если про них забыть.
