# Подсказка

Подсказка одна.

Выпишите, какие системные вызовы агент делает на самом деле, и найдите
в capabilities(7) имена, которые эти вызовы требуют. У агента такой
вызов ровно один — сырой сокет. Набор процесса строится из того, что
нужно, а не из того, что есть у root: всё лишнее из набора убирается
при старте, и тогда код, оказавшийся внутри процесса, унаследует только
эту одну возможность.
