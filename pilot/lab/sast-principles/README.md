# Лаба sast-principles: найди дефект и объясни находку

Два стенда с одинаковыми по смыслу дефектами на разных языках. В каждом
подставлены настоящие дефекты и рядом с ними чистый код похожей формы. Отчёты
трёх прогонов лежат готовыми; задача — не запустить инструмент, а прочитать
его вывод и объяснить каждую строку.

## Файлы

| файл | что это |
|---|---|
| `code/py/` | стенд на Python: шесть файлов, три подставленных дефекта |
| `code/go/` | стенд на Go: шесть файлов, четыре подставленных дефекта |
| `runs/bandit.txt` | сохранённый прогон bandit 1.9.4 по `code/py` |
| `runs/gosec.txt` | сохранённый прогон gosec 2.28.0 по `code/go` |
| `rules/local.yaml` | набор правил Semgrep для своего прогона, сети не требует |
| `answers.csv` | таблица на пятнадцать строк — её и надо заполнить |
| `key.yaml` | разметка; открывается после своей попытки |
| `check.py` | сверка `answers.csv` с разметкой, порог 14 из 15 |
| `hint.md` | одна подсказка |
| `solution.md` | решение отдельной задачи «почини» |

## Как запускать

```text
cd pilot/lab/sast-principles
../../../.venv-tools/bin/semgrep --config=rules/local.yaml \
    --metrics=off --no-git-ignore --jobs 1 code/
../../../.venv-tools/bin/python check.py
```

Свой прогон Semgrep идёт по локальному файлу правил и в сеть не ходит.
Прогоны bandit и gosec лежат готовыми: оба инструмента ставятся отдельно, и
воспроизвести их можно так.

```text
pip install bandit==1.9.4 && bandit -r code/py
go install github.com/securego/gosec/v2/cmd/gosec@v2.28.0 && gosec ./code/go/...
```

Числа детерминированы: сети нет, случайности нет, порядок строк отчёта задан
инструментом.

## Что сделать

Заполнить в `answers.csv` две колонки для каждой из пятнадцати находок.

* **вердикт** — одна буква: `и` истинная находка, `л` ложная, `д` дубль
  (то же место уже названо другим правилом выше по таблице).
* **признак** — одна фраза о том, по чему это видно в коде или в отчёте.
  Проверялка её не сверяет, но без неё строка не засчитывается: вердикт без
  признака — угадывание.

**Цель одной фразой:** получить от `check.py` совпадение не ниже, чем на
четырнадцати строках из пятнадцати.

## Отдельная задача «почини»

Сделать так, чтобы прогон bandit по `code/py` перестал печатать находку про
свёртку ключа кэша, — не выключая правило целиком и не трогая три настоящие
находки. Решение — в `solution.md`, открывается после своей попытки.
