# AppSec-guidebook

Учебный гайдбук по прикладной безопасности на русском: 134 темы
(этапы 0–3), 29 лабораторных, статический сайт.

Чтение: `site/index.html` после `make site` (сайт полностью офлайновый)
или опубликованная копия — адрес в `docs/reports/PAGES.md`.

## Что где лежит

| Путь | Назначение |
|---|---|
| `content/` | Темы гайдбука (источник истины, только читается конвейером) |
| `templates/` | Шаблоны тем (L1/L2/L3, уязвимость/инструмент) |
| `*.yaml` | Реестры: темы, источники, глоссарий, лабы, таксономия, аудит |
| `sources/` | Человекочитаемые выгрузки реестра источников (генерируются) |
| `GLOSSARY.md` | Глоссарий (генерируется из `glossary.yaml`) |
| `PLAYBOOK.md` | Свод правил производства |
| `SCHEMA.md` / `STYLE.md` | Схема темы / свод языка |
| `SCOPE.md` | Замороженный скоуп |
| `HANDOFF.md` | Журнал передачи работ между сессиями (новое сверху) |
| `journal/` | Снимки завершённых миссий (архив, не правится) |
| `docs/adr/` | Решения по архитектуре репозитория |
| `docs/reports/` | Живые отчёты о состоянии (инфраструктура, публикация, пилоты) |
| `research/` | Исследовательская база (заморожена) |
| `tools/` | Конвейер: проверки, сборка сайта, генераторы |
| `pilot/` | Лабораторные и semgrep-правила |
| `site/`, `build/`, `dist/` | Артефакты сборки (не в git) |

## Команды

```
make check    # все проверки, один вердикт (гейт)
make site     # сборка сайта + браузерная проверка
make phone    # однофайловая версия этапа 0 для телефона
make links    # внешние ссылки (единственная проверка с сетью)
make labs     # все лабы и сверка semgrep-правил (офлайн, .venv-tools и браузер)
make setup    # восстановление окружения с нуля
```

Остальные цели — в `Makefile`. Правила работы — в `PLAYBOOK.md`;
решение о структуре — `docs/adr/0001-repo-layout.md`.
